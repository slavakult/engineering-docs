# Engineering Docs

Демонстрационный проект технической документации, созданный для практики разработки документации в подходе Docs as Code.

## О проекте

Проект представляет собой документационный портал для условной программно-аппаратной платформы.

В репозитории представлены:

- пользовательская документация;
- инструкции по работе с системой;
- описание архитектуры;
- справочные материалы;
- API Reference;
- диаграммы и схемы;
- примеры структурирования технической документации.

Проект создан в учебных целях и не является официальной документацией реального продукта.

## Технологии

- Markdown
- MkDocs
- Material for MkDocs
- Mermaid
- Git
- GitHub Pages
