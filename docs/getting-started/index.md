# Начало работы

Раздел содержит основные сведения, необходимые для начала работы с системой.

Здесь описаны назначение и общая структура системы, порядок авторизации и основные действия, которые помогут быстро приступить к работе.

## Обзор системы

[Обзор системы](overview.md) содержит краткое описание назначения системы, основных разделов и доступных возможностей.

## Архитектура

[Архитектура](architecture.md) содержит общее представление о компонентах системы и их взаимодействии.

## Авторизация

Чтобы получить доступ к системе, необходимо пройти авторизацию.

Подробнее о способах входа и последовательности действий см. в разделе [Авторизация](authorization.md).

## Быстрый старт

Если Вы впервые работаете с системой, воспользуйтесь инструкцией [Быстрый старт](quick-start.md).

В ней приведена последовательность основных действий для начала работы с системой.

## Рекомендуемый порядок

Если Вы знакомитесь с системой впервые, рекомендуем изучать материалы в следующем порядке:

1. [Обзор системы](overview.md).
2. [Архитектура](architecture.md).
3. [Авторизация](authorization.md).
4. [Быстрый старт](quick-start.md).
