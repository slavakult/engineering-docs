# Обзор системы

!!! abstract "Назначение"

    **Engineering Portal** — единая веб-платформа для сопровождения полного жизненного цикла разработки электронных устройств.

    Система объединяет в одном интерфейсе инженерную документацию, библиотеку компонентов, складской учет, проекты, репозитории исходного кода, задачи разработки и средства коллективной работы.

![Главная страница системы](../assets/images/dashboard-home.png)

---

## Основные возможности

Engineering Portal предоставляет единое рабочее пространство для инженерной команды и позволяет отказаться от использования нескольких разрозненных сервисов.

<div class="grid cards" markdown>

-   :material-package-variant-closed:{ .lg .middle }

    **Склад компонентов**

    Управление электронной компонентной базой, контроль складских остатков, хранение технической информации и Datasheet.

-   :material-folder-multiple:{ .lg .middle }

    **Библиотека**

    Централизованное хранение инженерной документации, руководств, моделей, стандартов и внутренних документов.

-   :material-clipboard-text:{ .lg .middle }

    **Проекты**

    Управление инженерными проектами, спецификациями (BOM), архитектурой изделия и рабочими файлами.

-   :material-source-repository:{ .lg .middle }

    **Репозитории**

    Хранение исходного кода, организация структуры файлов и управление инженерными артефактами.

-   :material-view-kanban:{ .lg .middle }

    **Задачи**

    Планирование и сопровождение разработки с использованием Kanban-доски и режима списка.

-   :material-drawing:{ .lg .middle }

    **Инженерные доски**

    Создание архитектурных схем, черновиков, блок-схем и проектных набросков.

</div>

## Единое рабочее пространство

!!! info "Концепция"

    Все разделы системы доступны после авторизации и работают в рамках единого интерфейса.

    Пользователю не требуется переключаться между отдельными веб-приложениями или повторно проходить аутентификацию.

Типовой сценарий работы инженера выглядит следующим образом:

```text
Авторизация
      │
      ▼
Главная страница
      │
      ▼
Выбор проекта
      │
      ├────────► Работа с документацией
      │
      ├────────► Работа со складом
      │
      ├────────► Работа с репозиторием
      │
      ├────────► Выполнение задач
      │
      ▼
Завершение работы
```

!!! tip "Рекомендация"

    Перед началом работы рекомендуется ознакомиться со структурой проекта и назначенными задачами.

## Основные разделы системы

| Раздел | Назначение |
|---------|------------|
| Dashboard | Главная страница после авторизации |
| Warehouse | Управление компонентной базой |

## Интерфейс системы

После входа пользователь попадает на страницу **Mission Control**, которая является стартовой рабочей областью.

Основные элементы интерфейса:

- верхняя панель навигации;
- область быстрого доступа к разделам;
- главное рабочее пространство;
- встроенный корпоративный чат;
- центр уведомлений;
- форма обратной связи.

## Навигация

Для перехода между разделами используется меню **Navigation**.

![Меню навигации](../assets/images/navigation-menu.png)

Каждый раздел отвечает за отдельный этап инженерного процесса, однако все данные остаются связанными между собой.

Например:

- компонент склада может использоваться в нескольких проектах;
- задача может быть привязана к конкретному проекту;
- документация проекта связана с репозиторием;
- журнал изменений фиксирует все основные действия пользователей.
