# Обзор системы

Система предназначена для управления инженерными данными, проектами, компонентами и задачами в рамках единого рабочего пространства.

Она объединяет инструменты для работы с компонентами, проектной документацией, репозиториями, задачами и инженерными связями между объектами.

![Главная страница системы](../images/home.PNG)

> Главная страница системы.

## Основные возможности

Система объединяет следующие возможности:

- управление элементной базой и инженерными данными;
- хранение и организация файлов и материалов;
- создание и управление проектами;
- создание и управление задачами;
- работа с проектными материалами;
- работа с репозиториями;
- создание и использование инженерных досок;
- просмотр состава команды и распределения ролей.

## Основные разделы

Основные функции системы доступны через меню **Навигация**.

| Раздел | Назначение |
|---|---|
| Обзор | Главная рабочая область и доступ к основным функциям системы |
| Склад | Работа с элементной базой и инженерными данными |
| Библиотека | Хранение и организация файлов и материалов |
| Дефицит | Работа с дефицитными компонентами и связанными с ними данными |
| Проекты | Создание и управление проектами |
| Задачи | Создание и управление задачами |
| Repo | Работа с репозиториями и файлами проекта |
| Доски | Создание и редактирование инженерных чертежей, блок-схем и набросков |
| Команда | Просмотр участников команды и распределения ролей |

## Рабочее пространство проекта

Основная работа с инженерными данными выполняется в рамках проектов.

Проект объединяет связанные между собой компоненты, документы и другие данные. В рабочем пространстве проекта доступны инструменты для просмотра структуры проекта и работы с его содержимым.

Подробнее о работе с проектами см. в разделе [Проекты](../user-guide/projects.md).
