# Authentication API

Модуль **Authentication** предназначен для аутентификации пользователей и управления текущей сессией.

## Инициализация входа

```http
POST /api/v1/auth/login
```

### Тело запроса

```json
{
  "login": "engineer",
  "password": "engineer"
}
```

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `login` | `string` | Да | Идентификатор (логин) пользователя |
| `password` | `string` | Да | Код доступа (пароль) |

### Успешный ответ

```http
200 OK
```

```json
{
  "access_token": "eyJhbGciOiJIUzI1NiIs...",
  "token_type": "Bearer",
  "expires_in": 3600
}
```

Точный состав ответа определяется схемой `LoginResponse` в OpenAPI.

### Использование токена

```http
Authorization: Bearer <access_token>
```

## Ограничение попыток

Допускается не более пяти попыток аутентификации в течение одной минуты.

При превышении ограничения сервер возвращает:

```http
429 Too Many Requests
```

## Завершение сессии

```http
POST /api/v1/auth/logout
```

### Заголовок

```http
Authorization: Bearer <access_token>
```

### Ответ

```http
204 No Content
```

## Коды ответа

| Код | Описание |
|---|---|
| `200` | Аутентификация выполнена успешно |
| `400` | Некорректные данные запроса |
| `401` | Неверный идентификатор или код доступа |
| `429` | Превышено количество попыток |
| `500` | Внутренняя ошибка сервера |
