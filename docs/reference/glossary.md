# Глоссарий

В глоссарии приведены основные термины, используемые в документации SASCOM Platform.

Определения помогают единообразно понимать названия объектов, разделов и функций системы.

## Платформа и рабочая среда

### SASCOM Platform

Программная платформа для работы с инженерными данными, проектами, элементной базой, задачами, репозиториями и инженерными чертежами.

### Workspace

Рабочая среда пользователя в SASCOM Platform, объединяющая доступные разделы и объекты системы.

### Mission Control

Главная информационная страница системы, открывающаяся после авторизации. Содержит навигацию по разделам, презентационный материал и элементы быстрого доступа.

### Task Hub

Раздел для поиска, фильтрации и управления задачами. Поддерживает два представления: Board и List.

## Инженерные данные

### Элементная база

Набор электронных компонентов и связанных с ними технических данных, используемых в проектах.

### Datasheet

Техническая документация на электронный компонент, обычно представленная в формате PDF или в виде ссылки на внешний ресурс.

### 3D-модель

Трёхмерное представление электронного компонента, используемое для визуализации и работы с компонентом в САПР.

### BOM (Bill of Materials)

Спецификация компонентов, необходимых для изготовления или сборки изделия.

### Primary Silicon

Основная микросхема проекта, например микроконтроллер или ПЛИС.

### Архитектурный граф

Визуальное представление структуры и взаимосвязей между объектами или функциональными блоками проекта.

---

## Проекты

### Проект

Объект системы, объединяющий связанные инженерные данные, элементную базу, задачи, файлы и архитектурную информацию.

### Паспорт проекта

Набор основных характеристик проекта, включающий его семейство, платформу, основной компонент и другие параметры.

### Ревизия

Версия инженерного артефакта, например схемы, BOM или firmware, имеющая собственный идентификатор.

### Changelog

История значимых изменений, выполненных в рамках проекта, системы или её инженерных объектов.

---

## Задачи

### Задача

Элемент рабочего процесса, используемый для планирования, распределения и контроля выполнения работ.

### Kanban-доска

Представление задач в виде последовательности этапов рабочего процесса:

«Бэклог» → «В работе» → «На проверке» → «Готово».

Карточки задач можно перемещать между этапами.

### Приоритет

Характеристика важности задачи. В системе используются уровни:

- `Low`;
- `Medium`;
- `High`.

### План / Факт

Параметры задачи, отражающие запланированное и фактически затраченное на её выполнение время.

## Инженерные доски

### Доска

Рабочая область для создания интерактивных чертежей, схем и инженерных набросков.

### CAD-редактор (САПР)

Встроенный редактор инженерных чертежей и схем. Предоставляет инструменты рисования, размещения компонентов, добавления текста, заметок и комментариев.

### Компонент

Объект, размещаемый на инженерной доске. Может представлять электронный элемент, например резистор, конденсатор, катушку, диод или микросхему.

### NetLabel

Метка электрической сети на схеме, используемая для обозначения участков электрической цепи и их связи. В редакторе функция отображается как инструмент, находящийся в разработке.

## Репозитории

### Репозиторий (Repo)

Хранилище файлов проекта, организованное в виде дерева каталогов и файлов.

### Импорт репозитория

Добавление локального репозитория или его файловой структуры в систему с компьютера пользователя.

### Drag and drop

Способ добавления файлов и каталогов в репозиторий путём их перетаскивания из файловой системы компьютера в рабочую область системы.

---

## Команда

### Lead

Участник команды, отвечающий за техническое направление или координацию работ.

### Роль

Функциональная область ответственности участника команды, например:

- `Lead`;
- `Схемотехника`;
- `Разработка ПО`;
- `Конструкция`;
- другие направления.

## Интерфейс

### Чат SAS

Встроенный в платформу интерфейс рабочего чата на основе Rocket.Chat.

### Empty State

Состояние интерфейса, отображаемое при отсутствии данных в конкретном разделе или списке.

### CTA (Call to Action)

Элемент интерфейса, направляющий пользователя к целевому действию, например созданию объекта, сохранению изменений или переходу к следующему шагу.

### Микрокопия

Короткие тексты интерфейса: подписи кнопок, сообщения об ошибках, подсказки и другие элементы, сопровождающие действия пользователя.

### Placeholder

Текст-подсказка внутри поля ввода, показывающий пример ожидаемого значения. Обычно исчезает после начала ввода.

---

## API

### API (Application Programming Interface)

Программный интерфейс взаимодействия между системами или компонентами программного обеспечения.

### OpenAPI

Стандарт описания HTTP API, позволяющий формально определить доступные операции, параметры запросов, структуры данных и ответы API.

### Swagger UI

Веб-интерфейс для просмотра и интерактивного тестирования API на основе спецификации OpenAPI.
