# Справочная информация

Раздел содержит справочную информацию о системе, её объектах, терминах и используемых интерфейсах.

В отличие от **Руководства пользователя**, где описываются пользовательские сценарии и последовательность действий, справочная информация предназначена для быстрого поиска сведений о конкретном объекте или функции системы.

## Содержание

### Основные разделы

- **[Термины и определения](glossary.md)** — основные понятия и обозначения, используемые в системе.
- **[История изменений](changelog.md)** — журнал изменений, содержащий информацию о добавленных нововведениях, а также исправленых багов.
- **[Часто задаваемые вопросы](faq.md)** — ответы на часто задаваемые вопросы.

### API

[API Reference](../api-reference/index.md) — общая справочная информация о программном интерфейсе системы.

В Swagger UI методы сгруппированы по тегам:

- **Authentication** — авторизация и получение токена доступа. Методы: `login`, `logout`.
- **Warehouse** — работа с элементной базой. Методы: `getComponents`, `createComponent`, `importComponentsCsv`, `importFromDigiKey`.
- **Projects** — работа с проектами. Методы: `getProjects`, `createProject`, `getProject`, `updateProject`, `deleteProject`, `updateProjectStatus`.
- **Tasks** — работа с задачами. Методы: `getTasks`, `createTask`, `getTask`.

## Как пользоваться справочником

Если необходимо узнать значение термина или обозначения, используйте раздел **Термины и определения**.

Если требуется информация о конкретном объекте системы, перейдите в раздел **Объекты системы**.

Для получения технической информации о взаимодействии с системой программными средствами используйте **API Reference**.
