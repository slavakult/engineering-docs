# Руководство пользователя

Этот раздел содержит инструкции по работе с основными функциями системы.

Руководство построено по рабочим областям системы и помогает выполнять типовые операции: работать с данными, проектами, задачами, файлами и командой.

## Разделы руководства

| Раздел | Назначение |
|---|---|
| [Обзор](dashboard.md) | Работа с главной рабочей областью системы. |
| [Склад](warehouse.md) | Работа с элементной базой и данными. |
| [Библиотека](library.md) | Хранение и организация файлов и материалов. |
| [Проекты](projects.md) | Создание и управление проектами. |
| [Repo](repository.md) | Работа с репозиториями и файлами проекта. |
| [Задачи](tasks.md) | Создание и управление задачами. |
| [Доски](boards.md) | Работа с досками и визуальное представление задач. |
| [Команда](team.md) | Взаимодействие с участниками команды. |

## Как пользоваться руководством

Выберите раздел в зависимости от выполняемой задачи.

Если необходимо найти или добавить компонент, перейдите в раздел [Склад](warehouse.md).

Для работы с файлами и материалами используйте раздел [Библиотека](library.md).

Для создания и управления проектами перейдите в раздел [Проекты](projects.md).

Для работы с задачами и их статусами используйте разделы [Задачи](tasks.md) и [Доски](boards.md).

Для работы с файлами проекта и репозиториями перейдите в раздел [Repo](repository.md).

Информация об участниках рабочего пространства приведена в разделе [Команда](team.md).
