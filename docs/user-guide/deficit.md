# Дефицит

Раздел **Дефицит** содержит отчёт о недостающих компонентах на складе. Он помогает определить, каких деталей не хватает и какое количество необходимо приобрести.

## Отчёт по дефициту

На странице расположен отчёт **«Отчёт по дефициту»**, в котором представлен список недостающих деталей.

Для каждой детали отображаются следующие сведения:

- **Название** — наименование компонента.
- **Производитель** — компания, выпускающая компонент.
- **Необходимое количество** — количество деталей, которое требуется.
- **Дефицит** — количество недостающих деталей.
- **Стоимость** — стоимость компонента.

Используйте отчёт, чтобы определить недостающие позиции и оценить расходы на их приобретение.
