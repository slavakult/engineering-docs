# Документация SasCom

SasCom — это набор инструментов разработчика для создания и реализации технического решения. Все инструменты доступны через интернет в одном веб-приложении: устанавливать и настраивать что-либо на своём компьютере не нужно. Рабочие данные хранятся в личном кабинете разработчика.

![cover](images/cover.png)

## С чего начать

Если вы впервые работаете с системой, начните с раздела **Getting Started**:

- [Обзор системы](getting-started/overview.md) — назначение и основные возможности системы.
- [Архитектура](getting-started/architecture.md) — общее представление о структуре системы.
- [Авторизация](getting-started/authorization.md) — вход в систему.
- [Быстрый старт](getting-started/quick-start.md) — основные действия для начала работы.
