## О проекте

Этот сайт — демонстрационный проект технической документации, созданный
для практики разработки документации в подходе Docs as Code.

В проекте представлены:

- пользовательская документация;
- инструкции по работе с функциональными возможностями системы;
- описание архитектуры;
- справочные материалы;
- API Reference;
- примеры структурирования и оформления технической документации.

Документация хранится в Git-репозитории в формате Markdown и публикуется
в виде статического документационного портала.

### Цель проекта

Продемонстрировать полный цикл работы технического писателя: от анализа
исходных материалов и структурирования информации до разработки
документации, её оформления с помощью диаграмм и публикации.

**Область применения:** демонстрационный материал. Документация создана
в рамках портфолио и воспроизводит структуру, стиль и процессы, принятые
в технической документации существующего коммерческого продукта.

## Об авторе

Я технический писатель с опытом более 5 лет в разработке технической,
пользовательской и эксплуатационной документации для
аппаратно-программных комплексов и программных продуктов.

В работе занимаюсь подготовкой технических заданий, описанием требований
и бизнес-процессов, разработкой эксплуатационной и пользовательской
документации, документированием интерфейсов и REST API. Взаимодействую
с разработчиками, аналитиками, тестировщиками и другими специалистами
на разных этапах жизненного цикла продукта.

В качестве инструментов и технологий использую Markdown, Git,
Swagger/OpenAPI, Postman, Draw.io, PlantUML, Figma, SQL и Python.
Развиваю навыки системного анализа и современных подходов к техническому
письму, включая Docs as Code.
